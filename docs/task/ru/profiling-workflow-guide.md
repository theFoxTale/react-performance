## Этап 1: Начальное профилирование (базовое)

**Примечание:** Перед началом подготовьтесь сохранять скриншоты в директорию `performance-starter/screenshots/baseline/`.

### Шаг 1: Запись базовой производительности

#### Запись сеанса профилирования

1. **Откройте Profiler React DevTools**
   - Нажмите F12, чтобы открыть DevTools
   - Перейдите на вкладку "Profiler"
   - Нажмите кнопку "Start profiling" (значок круга)

2. **Выполните следующие действия** (по одному, отдельные записи):

   **Действие A: Сортировка стран**
   - Нажмите кнопку сортировки для сортировки по населению
   - Дождитесь завершения рендеринга
   - Нажмите "Stop profiling"

   **Действие B: Поиск стран**
   - Введите "United" в строку поиска
   - Дождитесь обновления результатов
   - Нажмите "Stop profiling"

   **Действие C: Смена года**
   - Выберите другой год в селекторе года
   - Дождитесь обновления данных
   - Нажмите "Stop profiling"

   **Действие D: Переключение колонки**
   - Откройте модальное окно колонок
   - Включите/выключите колонку
   - Закройте модальное окно
   - Нажмите "Stop profiling"

3. **Проанализируйте каждую запись**

   Для каждого действия зафиксируйте:
   - Длительность коммита
   - Длительность рендеринга
   - Flame-диаграмму

### Шаг 2: Документирование базовых результатов

Обновите файл `PERFORMANCE.md`, добавив в него записанные базовые измерения.
